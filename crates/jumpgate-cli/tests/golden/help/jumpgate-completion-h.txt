Set up jumpgate's completion in a shell

Usage: jumpgate completion [OPTIONS] <COMMAND>

Commands:
  install  Install jumpgate's completion where the shell loads it
  check    Check that jumpgate's installed completion file matches this jumpgate
  print    Print jumpgate's completion registration script for a shell

Options:
  -h, --help  Print help (see more with '--help')

Global flags: --json, --fields <FIELD>, --long, --full, --no-input. `jumpgate completion --help` describes them.
