Read the declarations of a set of repositories and write the need records and the offers each app provides.

This version of jumpgate does not build needs yet, and the command fails with jumpgate::command::not_built.

Usage: jumpgate needs [OPTIONS]

Options:
      --json
          Print the result as a JSON document. The default prints text.

      --no-input
          Fail instead of asking a question

  -h, --help
          Print help (see a summary with '-h')

Examples:
  jumpgate needs
          Read the declarations and write the need records (not built yet)

Effects: read-only, closed-world.
