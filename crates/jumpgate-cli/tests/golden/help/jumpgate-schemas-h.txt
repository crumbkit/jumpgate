Explore the JSON documents that jumpgate prints

Usage: jumpgate schemas [OPTIONS] <COMMAND>

Commands:
  list  List the JSON documents that jumpgate prints, with a description of each
  show  Print the JSON Schema of each document

Options:
  -h, --help  Print help (see more with '--help')

Global flags: --json, --fields <FIELD>, --long, --full, --no-input. `jumpgate schemas --help` describes them.
Next: jumpgate schemas <COMMAND> -h
