Match what each app needs to what a provider offers, and check the plan

Usage: jumpgate [OPTIONS] <COMMAND>

Turn declarations into a checked plan
  needs       Read the declarations of a set of repositories and write the need records and the offers each app provides
  resolve     Match each need to an offer for one target, write the plan and list the needs that nothing binds
  check       Run every check on a plan, whichever matcher wrote it

Explore commands
  commands    Explore jumpgate's commands
  schemas     Explore the JSON documents that jumpgate prints

Install jumpgate's skill
  skills      Give coding agents jumpgate's skill

Set up shell completion
  completion  Set up jumpgate's completion in a shell

Options:
      --json
          Print the result as a JSON document. The default prints text.

      --fields <FIELD>
          Print only these comma-separated fields, in this order. The default prints the compact columns.

      --long
          Add the long columns after the compact ones. The default prints only the compact columns.

      --full
          With --json, print every field of every row. The default prints only the fields of the columns.

      --no-input
          Fail instead of asking a question

  -h, --help
          Print help (see a summary with '-h')

  -V, --version
          Print version

Topics: exit-codes. `jumpgate help <TOPIC>` prints one.
