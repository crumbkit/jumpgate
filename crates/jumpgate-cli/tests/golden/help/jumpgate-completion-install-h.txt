Install jumpgate's completion where the shell loads it

Usage: jumpgate completion install [OPTIONS]

Options:
      --shell <SHELL>  Install for this shell in place of the one that SHELL names [possible values: bash, elvish, fish, powershell, zsh]
      --force          Replace a file or a link that install did not write; a link's target stays as it is
  -h, --help           Print help (see more with '--help')

Examples:
  jumpgate completion install --shell fish
  jumpgate completion install --shell zsh --force

Effects: additive, idempotent, closed-world.
Global flags: --json, --fields <FIELD>, --full, --no-input. `jumpgate completion install --help` describes them.
Next: jumpgate completion install --help explains each column.
